**"Learn Claude Code"** is a hands-on course teaching **harness engineering** — the art of building the environment (tools, permissions, memory, task systems, and agent teams) that surrounds an AI model so it can operate effectively.

It consists of **17 progressive lessons** (s01–s17), each isolating one harness mechanism — from a basic agent loop and tool use, all the way to multi-agent teams, workflow orchestration, and goal-controlled loops.

The core philosophy is: **agency comes from the model (e.g., Claude), not from code** — your job as a developer is to build the "vehicle" (the harness), and the model will do the rest.
