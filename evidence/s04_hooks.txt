## 📘 Overview

**"Learn Claude Code — Harness Engineering for Real Agents"** is a tutorial repository that teaches you how to build the **harness** (operational environment) for AI agents. The core philosophy is:

> **Agency comes from the model (training), not the code. Your job is to build the vehicle, not the driver.**

---

## 🧠 Key Concepts

- **Agent = Model + Harness**
- The **model** (e.g., Claude) supplies intelligence.
- The **harness** supplies: Tools, Knowledge, Observation, Action Interfaces, and Permissions.
- The repo uses **Claude Code** as a reference implementation because it exemplifies a minimal, elegant harness.

---
