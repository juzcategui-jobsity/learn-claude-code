## Code Review: `s01_agent_loop/code.py`

### Summary
A clean, minimal agent loop implementation that feeds bash tool results back to an LLM until it stops calling tools. Well-structured educational code, but has a few security and robustness concerns worth noting.

---

### Critical Issues

1. **Weak command blocklist** (line ~57): The `dangerous` list is trivially bypassed.
   - Impact: `rm -rf /tmp/../` or `sudo -i` or `shutdown -h now` all slip through.
   - Fix: Use an allowlist approach or at minimum use regex with word boundaries; consider sandboxing (Docker, `firejail`).

2. **`shell=True` with unsanitized input** (line ~62): `subprocess.run(..., shell=True)` passes the raw user/LLM-generated command string to `cmd.exe`/`sh`.
   - Impact: Shell metacharacter injection (e.g., `&&`, `|`, `;`) can chain arbitrary commands.
   - Fix: For a teaching tool this is acceptable, but production code should avoid `shell=True` or sanitize thoroughly.

---

### Improvements

1. **No conversation length / token limit** (line ~74): `history` grows unboundedly across sessions.
   - Fix: Truncate or summarize old messages to avoid hitting context window limits silently.

2. **`MODEL_ID` crashes without a clear error** (line ~40): `os.environ["MODEL_ID"]` raises a raw `KeyError` if unset.
   - Fix: Use `os.environ.get("MODEL_ID")` with a descriptive error message or a sensible default.

3. **Output truncated silently** (line ~65): `out[:50000]` cuts output with no indication to the model.
   - Fix: Append `"\n[output truncated]"` so the LLM knows the result is incomplete.

4. **`readline` bindings are macOS-specific comments** (line ~33): The comment says "macOS libedit" but the code runs unconditionally on all platforms.
   - Fix: Guard with `sys.platform == "darwin"` if the fix is Mac-specific.

---

### Positive Notes
- ✅ The agent loop pattern itself is textbook-clean and easy to follow — great for teaching.
- ✅ Cross-platform awareness (`os.name == "nt"` for Windows) is well handled.
- ✅ Timeout on subprocess prevents indefinite hangs.
- ✅ `errors="replace"` avoids encoding crashes on binary output.
- ✅ ANSI color codes use `\001/\002` readline width markers — a nice touch.

---

### Verdict
- [x] **Needs minor changes** — solid educational code; the blocklist and `shell=True` issues should be documented with clear warnings since learners may copy this pattern into production.
